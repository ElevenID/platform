# Source origin and license

The initial platform extraction originates in
[ElevenID/marty-ui](https://github.com/ElevenID/marty-ui) at commit
[`9e098423b5d98bc1bb50147f6cf1412973256144`](https://github.com/ElevenID/marty-ui/tree/9e098423b5d98bc1bb50147f6cf1412973256144).

Original authors and contributors retain their copyright. This extraction uses
AGPL-3.0-only and preserves the original `LICENSE` bytes. Repository naming does
not change package names, image identities or upstream licensing.

`migration/source-map.json` records each imported file's original path, Git blob
SHA, content SHA-256 and the last observed source change where history proves
it, along with the initial extracted bytes and any adaptation. The source
checkout is shallow: when file history stops at a shallow boundary,
`last_changed_commit` is null and `history_boundary_commit` plus
`history_truncated` record that limit; the boundary is not represented as the
file's actual last modification. It also records the two source files from which the
small product identity module was derived. The source history remains accessible
in the linked repository; this initial destination commit is an attributed
snapshot, not a rewritten import of the monorepo's full history.

Producer identities are intentionally retained as `ElevenID/marty-ui`. They
identify the source of already signed artifacts, not the location of these
consumer scripts. No private commerce source, cloud configuration, customer
data or credentials are included in this extraction.
